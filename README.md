# Vibe Coding vs AI Pair Programming

## Task Manager App

This project builds the same task manager using two different AI-assisted approaches.

### Vibe Version

Tool used: Google AI Studio

Features:
- Add a task
- Mark a task as complete
- Filter tasks by All, Active, and Completed

### Pair Version

Tool used: GitHub Copilot

Features:
- Add a task
- Mark a task as complete
- Filter tasks by All, Active, and Completed

## Comparison Table

| Dimension | Vibe Version | Pair Version | Verdict |
|---|---|---|---|
| Speed | Generated the complete application from one prompt and was running quickly. | Built file by file with Copilot assistance. | Vibe was faster to first working version. |
| Control | AI decided the generated project structure and implementation. | I decided the file structure and reviewed Copilot suggestions. | Pair gave more control. |
| Code Quality | Generated project contained multiple files and framework code. | Code was built in smaller, understandable files. | Pair was easier to keep simple. |
| Explainability | I had to inspect generated code to understand its structure. | I understood the code while building it with Copilot. | Pair was easier to explain. |
| Editability | Changes can require understanding generated project structure. | Individual HTML, JavaScript, and CSS changes were straightforward. | Pair was easier to edit. |

## When I Would Use Each Tool

**Vibe coding tool for:** quickly creating a working prototype because the complete task manager was generated from one prompt.

**AI pair programming for:** projects where I need more control and understanding of the code because I build and review the implementation step by step.
